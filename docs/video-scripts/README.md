## Script Format

Each script follows this structure:

```
# Title
Metadata (audience, duration, screen focus)

Pre-Production Notes
Scene 1 — Introduction
Scene N — [Topic]
...
Post-Production Notes
```

**Scene blocks include:**
- `[SCREEN:]` — what is currently visible on screen
- `[ACTION:]` — what the presenter clicks or types
- `**Narrator:**` — spoken narration text (in blockquotes)
- `[CALLOUT BOX:]` — on-screen text overlays

## Production Guidelines

- Record at 1920×1080 minimum resolution
- Use demo account data — never real student/parent data in recordings
- Add animated arrows for all click targets
- Include chapter markers at each scene timestamp
- End each video with a link to the next in the series
- Subtitle files (.srt) should be generated for accessibility
