# Video Tutorial Script: School Settings & Initial Configuration

**Workflow:** Configuring school profile, academic year, fee heads, and role permissions
**Audience:** School admins, super admins
**Estimated Duration:** 6–7 minutes
**Screen Recording Focus:** School Dashboard → Settings module

---

## Pre-Production Notes

- Use a fresh demo account to show first-time setup
- Walk through the recommended setup order: Profile → Academic Year → Classes → Fee Heads → Permissions
- This video is best watched before all other tutorials as it covers prerequisites

---

## Scene 1 — Introduction [0:00–0:25]

**[SCREEN: Dashboard home page — first login, sparse data]**

**Narrator:**
> "Before using EMS day-to-day, you need to configure your school. This tutorial is designed for admins setting up EMS for the first time — covering school profile, academic year, classes, fee heads, and role permissions. We recommend watching this before any other tutorial."

---

## Scene 2 — School Profile [0:25–1:30]

**[ACTION: Click "Settings" in the left sidebar → "School Profile"]**

**Narrator:**
> "Click 'Settings' in the left navigation, then 'School Profile'."

**[SCREEN: School Profile form]**

> "Fill in your school's full name, address, phone number, and website. Upload your school logo — this appears on report cards, fee receipts, and all printable documents."

**[ACTION: Fill school name, address, upload logo]**

> "Set your school's affiliation board — CBSE, ICSE, State Board, or International. This affects exam grading options available later."

**[ACTION: Select affiliation board]**

> "Enter the Principal's name and contact email. Click 'Save Profile'."

**[ACTION: Click Save]**

**[CALLOUT BOX: "Your logo appears on all PDFs and receipts — use a high-resolution PNG for best quality"]**

---

## Scene 3 — Academic Year Setup [1:30–2:30]

**[ACTION: Click "Academic Year" in Settings sidebar]**

**Narrator:**
> "Next, configure your academic year. Click 'Academic Year' in the settings."

**[SCREEN: Academic Year page]**

> "Click 'Create New Academic Year'. Enter the year label — for example, '2025-2026'. Set the start and end dates. Most schools run April to March or June to May."

**[ACTION: Fill year label, start date April 1, end date March 31]**

> "Mark this year as 'Active' — the active academic year is used by default for all new students, fees, and exams."

**[ACTION: Toggle Active checkbox]**

> "Click 'Save'. You can have multiple academic years — past years are archived but remain accessible for record retrieval."

**[ACTION: Click Save]**

---

## Scene 4 — Create Classes and Sections [2:30–3:20]

**[ACTION: Click "Classes" in main nav → Click "Add Class"]**

**Narrator:**
> "Now create your classes. Go to 'Classes' in the main menu and click 'Add Class'."

**[SCREEN: Add Class form]**

> "Enter the class name — for example 'Grade 1'. Add sections: A, B, C. Set the maximum student capacity per section."

**[ACTION: Fill class name, add sections, set capacity]**

> "Repeat for each grade level in your school. Most schools do this in bulk at the start of the year."

**[CALLOUT BOX: "Tip: You can bulk-import classes from Excel — check the Import button"]**

---

## Scene 5 — Configure Fee Heads [3:20–4:20]

**[ACTION: Click "Settings" → "Fee Configuration" → "Fee Heads"]**

**Narrator:**
> "Fee heads define the categories of fees your school charges — like Tuition, Transport, Exam Fee, Library Fee, and so on."

**[SCREEN: Fee Heads list]**

> "Click 'Add Fee Head'. Enter the name, select whether it's mandatory or optional, and set whether it's a one-time or recurring charge."

**[ACTION: Add Fee Head: Tuition Fee, Mandatory, Monthly Recurring]**

> "Add all the fee heads your school uses. These appear as columns in each student's fee structure."

**[ACTION: Add 2–3 more fee heads]**

> "Once fee heads are set, go to 'Fee Templates' to define standard fee amounts per class. Templates save time — instead of setting fees per student, you apply a template to an entire class."

**[ACTION: Navigate to Fee Templates, show template creation]**

---

## Scene 6 — Role & Permission Management [4:20–5:30]

**[ACTION: Click "Settings" → "Roles & Permissions"]**

**Narrator:**
> "EMS supports role-based access control. By default, there are four roles: Admin, Teacher, Accountant, and Front Desk."

**[SCREEN: Roles list with permission toggles]**

> "Click a role to see and edit its permissions. For example, you can restrict Teachers so they can only view — not edit — student profiles."

**[ACTION: Click 'Teacher' role, show permissions grid]**

> "Permissions are grouped by module. Toggle each permission on or off. Changes take effect immediately for all users with that role."

**[ACTION: Toggle off 'Edit Student' permission for Teacher role]**

> "You can also create custom roles — useful for specialized staff like Librarians or Transport Managers."

**[ACTION: Click 'Add Custom Role', name it 'Librarian', set permissions]**

---

## Scene 7 — Invite Admin Users [5:30–6:00]

**[ACTION: Click "Settings" → "Users" → "Invite User"]**

**Narrator:**
> "Finally, invite other admin users. Click 'Invite User', enter their email, assign a role, and click Send Invite. They'll receive an email to set up their password."

**[ACTION: Fill email, select Admin role, click Send Invite]**

**[SCREEN: Invited user appears in Users list with Pending status]**

---

## Scene 8 — Recommended Setup Order [6:00–6:30]

**[SCREEN: Settings menu overview]**

**Narrator:**
> "Here's the recommended setup order for new schools:
> 1 — School Profile,
> 2 — Academic Year,
> 3 — Classes and Sections,
> 4 — Subjects,
> 5 — Fee Heads and Templates,
> 6 — Staff members,
> 7 — Enroll students.
> Following this order prevents data dependency issues."

**[SCREEN: Numbered checklist of setup steps]**

---

## Scene 9 — Recap [6:30–7:00]

**[SCREEN: Settings page showing configured sections]**

**Narrator:**
> "To recap: Start in Settings to configure your school profile and academic year. Create classes, define fee heads, configure role permissions, and invite admin users. With setup complete, you're ready to enroll students and start using EMS."

> "Thank you for watching the EMS tutorial series. Check the Help Center for more in-depth guides on each module."
